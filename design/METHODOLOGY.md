# Visual-identity methodology (Rudolf Krylov portfolio)

Working method used to generate the identity rounds in `design/mockups` + `design/palettes`.

## 1. Strategy first (brand pyramid)
Essence → personality → values → emotional benefit → functional benefit, plus a one-line
**message** a recruiter remembers. For Rudolf: *"Disciplined systems, honestly built —
an architect who ships and can defend every decision."*

## 2. Five-element system (RampStack)
Design each: **logo** (mark + icon + lockups, legible at 16px, single-colour) · **color**
(1 brand colour + neutrals + one accent; WCAG AA) · **typography** (display / body / mono,
scale, pairing) · **imagery** (direction + what's out of bounds) · **motion** (restraint,
reduced-motion). Constraint over sprawl.

## 3. Provenance over defaults (anti-"AI look")
Ground each identity in a **specific, named design language** (Ferrari chiaroscuro, WIRED
broadsheet, Bauhaus, Paris zinc, kintsugi, Go, letterpress…) — never the generic AI clusters:
warm-cream + serif + terracotta, dark + neon, purple-blue gradient, Inter/Space-Grotesk,
rounded pills, emoji markers, evenly-sterile minimal.

## 4. Concept metaphor
The strongest identities carry a **metaphor from Rudolf's world** (dojo, métro, circuit,
kintsugi, orrery, seismograph…) expressed through a custom signature graphic, not decoration.

## 5. Personal-as-product layer  ← added 2026-08-02
A **light** product-marketing framing so the site reads as "here is what I offer" without
being flashy:
- a **value proposition** line (what you get);
- capabilities framed as **specs / features** (not a wall of adjectives);
- **one** restrained call-to-action;
- evidence as quiet **social proof** (live GitHub stats, "what I can defend").
Rule: **readability first** — the product cues stay understated; if a touch competes with the
content or feels salesy, cut it. Subtle > loud.

## 6. Always
Dark + light themes (tokenised); bilingual FR/EN; geometric-grotesque display + technical mono;
deep negative space; one accent; palettes saved to `design/palettes/` every round.

## 7. Palette Atlas  ← added 2026-08-02
The color decision is isolated in `design/palettes/palettes-50.md` — 50 palettes
(cool-dominant, dark+light variants each, 10 bold, concept-tagged, sources credited),
visualized in-use in the "Palette Atlas" artifact. Pick palette → apply to chosen concept.

## 8. Exploration Atlas  ← added 2026-08-02
Counter-round on request: `design/palettes/palettes-50-explore.md` — 50 palettes deliberately
outside stated tastes (warm/pastel/pop/retro/luxe/gourmand), typography customized per palette
(35 researched display faces). Purpose: test the boundaries of the "no" list before locking.
